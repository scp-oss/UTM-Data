# UTM Дашборд

Веб-приложение на Go для мониторинга нескольких УТМ (Универсальный
транспортный модуль ЕГАИС): хранит список УТМ по IP-адресу, периодически
опрашивает их HTTP API, показывает организацию (ИНН/название), адрес
установки и сроки действия сертификата доступа к ЕГАИС и ГОСТ-сертификата,
и присылает уведомления в Telegram за 30, 10, 5, 2 и 1 день до истечения
любого из сертификатов.

## ⚠️ Важно: адаптируйте клиент УТМ под реальный API

Модуль `internal/utmclient/client.go` опрашивает `GET http://<ip>:<port>/info`
и разбирает XML-ответ по схеме, реконструированной по общедоступным
описаниям локального HTTP API УТМ ФСРАР — **не по официальному PDF**
(`https://fsrar.gov.ru/opendata/dist/documentation.pdf`), потому что доступ
к `fsrar.gov.ru` заблокирован политикой сети в среде, где писался этот код.

Если реальный путь эндпоинта или имена XML-полей отличаются — это
**единственный файл**, который нужно поправить: измените `InfoPath` и теги
структуры `infoResponse`, при необходимости — сопоставление типов
сертификатов в `certificateKind()`. Чтобы упростить эту доработку, сырой
ответ УТМ всегда сохраняется в БД (поле `last_raw_response`) — его удобно
посмотреть в логах после первого реального опроса и поправить парсер по
факту.

## Возможности

- Форма добавления УТМ — нужен только IP-адрес (и опционально порт, название).
- ИНН, название организации, адрес установки, сроки действия сертификата
  ЕГАИС и ГОСТ-сертификата подтягиваются автоматически при опросе.
- При добавлении УТМ опрашивается сразу; далее — по расписанию.
- Расписание опроса (1 или 2 раза в сутки, время ЧЧ:ММ) задаётся на
  странице «Настройки», без перезапуска приложения.
- Кнопка ручного опроса каждого УТМ отдельно.
- Список получателей Telegram-уведомлений (chat_id) с возможностью
  добавления/удаления и тестовой отправки.
- Уведомления об истечении сертификата ЕГАИС и ГОСТ-сертификата — за 30, 10,
  5, 2 и 1 день; при продлении сертификата (изменении даты окончания)
  расписание уведомлений сбрасывается автоматически.
- Работает как обычный Go-бинарник (без контейнера) или в Docker.
- База данных — SQLite (файл), драйвер на чистом Go, без cgo.

## Запуск без контейнера

Требуется Go 1.25+.

```bash
go build -o utm-dashboard .
DB_PATH=./data/utm-dashboard.db HTTP_ADDR=:8088 ./utm-dashboard
```

Откройте `http://localhost:8088`.

## Запуск в Docker

```bash
docker compose up -d --build
```

Приложение будет доступно на `http://localhost:8088`, база данных
сохраняется в `./data/utm-dashboard.db` на хосте.

## Конфигурация

Через переменные окружения (только то, что нужно на старте процесса):

| Переменная  | По умолчанию                 | Назначение                          |
|-------------|-------------------------------|--------------------------------------|
| `HTTP_ADDR` | `:8088`                       | Адрес веб-интерфейса дашборда        |
| `DB_PATH`   | `./data/utm-dashboard.db`     | Путь к файлу базы данных SQLite      |

Всё остальное (токен Telegram-бота, получатели, расписание опроса)
настраивается в веб-интерфейсе на странице «Настройки» и хранится в БД.

## Настройка Telegram-бота

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Вставьте токен на странице «Настройки».
3. Узнайте chat_id получателя (например, через
   [@userinfobot](https://t.me/userinfobot) для личных сообщений, либо
   добавив бота в группу — для групповых уведомлений chat_id отрицательный).
4. Добавьте chat_id на странице «Настройки» и отправьте тестовое сообщение.

## Структура проекта

```
main.go                     — точка входа, сборка компонентов, graceful shutdown
internal/config              — конфигурация из переменных окружения
internal/models               — доменные типы
internal/db                    — открытие SQLite и схема (schema.sql)
internal/store                  — доступ к данным (CRUD)
internal/utmclient               — опрос HTTP API УТМ (см. предупреждение выше)
internal/notifier                 — отправка сообщений в Telegram
internal/scheduler                 — расписание опроса и логика уведомлений
internal/web                        — HTTP-обработчики и HTML-шаблоны
```
